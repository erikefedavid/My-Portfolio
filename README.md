# My Portfolio

Responsive personal portfolio showcasing my projects, skills, and contact section.  
Built with **React**, **Tailwind CSS**, and **EmailJS**.

## ✨ Features
- Project showcase with live links
- About & Skills section
- Contact form powered by EmailJS
- Smooth animations and transitions
- Fully responsive design

## 🛠️ Tech Stack
- React
- Tailwind CSS
- EmailJS

## 🚀 Getting Started
```bash
git clone https://github.com/erikefedavid/My-Portfolio.git
cd My-Portfolio
npm install
npm run dev
